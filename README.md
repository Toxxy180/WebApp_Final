## เปิดใช้งาน

เปิด `dist/index.html` ในเบราว์เซอร์ได้โดยตรง หรือใช้ static HTTP server กับโฟลเดอร์ `dist` ไม่ต้องติดตั้ง dependencies หรือ build ฟอนต์และ PDF อยู่ในโครงการ จึงอ่านแบบออฟไลน์ได้หลังดาวน์โหลดไฟล์ครบ

หน้าที่เผยแพร่บน Sites ใช้ `.openai/hosting.json` เป็นตัวระบุไซต์และโฟลเดอร์ static ข้อมูลความคืบหน้า คำตอบ และคะแนนสูงสุดอยู่ใน localStorage ของเบราว์เซอร์ ไม่ได้ส่งไปเซิร์ฟเวอร์

## โครงสร้าง

- `dist/content.js` — แหล่ง PDF และตัวช่วยสร้างแบบทดสอบ
- `dist/ch01-03.js` — HTTP, HTML/สื่อ/การใส่ JS, CSS
- `dist/ch04-05.js` — พื้นฐาน JavaScript และ Functions
- `dist/ch06-07.js` — Arrays และ Objects/JSON
- `dist/ch08-10.js` — DOM/Events, Modules และแนวคิดก่อนใช้ React
- `dist/app.js` — routing, search, progress, quiz และการตรวจคำตอบ
- `dist/styles.css` — หน้าคอมพิวเตอร์/มือถือ/พิมพ์
- `dist/sources` — PDF ต้นฉบับที่ไม่แก้ไข
- `dist/fonts` — Noto Sans Thai พร้อม SIL Open Font License
- `design` — ภาพแนวทาง UI จาก ImageGen สำหรับหน้า reader และ quiz
